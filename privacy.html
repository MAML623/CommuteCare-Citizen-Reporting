Privacy Policy

CommuteCare is a student-developed citizen reporting website prototype designed to demonstrate how commuters can report and track transportation-related concerns.

This policy explains how information is collected, used, and stored within the prototype, including its integration with Firebase Cloud Firestore.

1. Information Collected

When submitting a report, users provide information such as:

  • Full name, email address, and contact number.
  • Issue category and description.
  • Severity level and date and time observed.
  • Location and nearby landmarks.
  • Optional photo filename.

CommuteCare also generates a report reference number and records the submission date and report status. Firebase Authentication creates an anonymous user identifier to associate reports with their submitter.

2. How Information Is Used

Submitted information is used to demonstrate report submission, reference number generation, report tracking, and dashboard functionality.

The information is not automatically forwarded to LRMC, local government units, or other agencies. Report statuses shown in the prototype do not represent actual government processing.

3. Data Storage

CommuteCare uses Firebase Cloud Firestore to store submitted report information in an online database.

The website also saves a copy of submitted reports in the browser's localStorage to support its existing tracking functionality.

Firebase Authentication is used to assign visitors an anonymous account. Cloud reports are stored under that account's unique identifier.

This means reports can remain in the cloud after the page is refreshed or browser storage is cleared. However, clearing browser data may also remove the anonymous account credentials needed to retrieve those reports through the website.

4. Photo Uploads

Users may select JPG, PNG, or WebP images up to 10 MB as optional supporting evidence.

The current prototype validates the selected file but stores only its filename. The actual image is not uploaded to Firebase Storage or retained by the reporting system.

5. Data Privacy and Security

CommuteCare uses Firebase Authentication and Firestore Security Rules to restrict access to reports based on the anonymous user account that created them.

Visitors cannot use the website's Firestore access to read reports belonging to other anonymous users. Authorized Firebase project administrators may still access stored information through the Firebase Console.

Browser localStorage may also contain report details, including personal information, and may be accessible to other people using the same browser or device.

These measures do not guarantee complete security. CommuteCare is an educational prototype and has not undergone a comprehensive security assessment.

6. Data Retention

Locally saved reports may remain available after refreshing the page. Clearing the website's localStorage removes those local copies.

Reports saved in Firebase Cloud Firestore remain stored until they are deleted through an authorized administrative process. The current prototype does not automatically delete cloud reports or provide users with an in-app deletion feature.

Users may contact the project team to request assistance concerning stored demonstration data. Providing the report reference number may help identify the relevant record.

7. Prototype Limitations

CommuteCare is not an official reporting platform operated by LRMC, an LGU, or any government agency.

Although the website uses a real cloud database, submitted reports are not sent to government agencies for official review or action.

The current dashboard displays demonstration reports, reports stored in the browser, and Firebase reports belonging to the current anonymous account. It is not an official administrative dashboard.

The website does not currently support official status updates, cross-device account recovery, or secure public report lookup using only a reference number.

8. Contact

For questions about the prototype or requests concerning demonstration data, visit our Contact Us section.

Important Prototype Notice

CommuteCare is intended for educational and demonstration purposes only. Please use fictional information when testing the system. Do not submit actual sensitive personal information or emergencies through this website.
